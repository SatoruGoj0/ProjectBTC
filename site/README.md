# Baku Tattoo Community — сайт-визитка

Одностраничный сайт комьюнити на три языка (AZ / RU / EN) с 3D-знаком на WebGL.

**Стек:** Next.js 16 (App Router) · React 19 · TypeScript · Tailwind v4 · Three.js + React Three Fiber + postprocessing · Lenis.

---

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть <http://localhost:3000> — корень редиректит на язык по заголовку `Accept-Language`
(`/az`, `/ru`, `/en`).

```bash
npm run build
```

## Что нужно заполнить перед публикацией

Всё фактическое собрано в двух файлах. Ищите пометку `TODO`.

### 1. `src/lib/site.ts` — контакты и цифры

| Поле | Что это |
| --- | --- |
| `foundedYear` | Год основания. Показывается в шапке героя и считает «лет вместе». |
| `url` | Боевой домен. Нужен для canonical, Open Graph и `sitemap.xml`. |
| `instagram`, `instagramHandle` | Профиль комьюнити. |
| `email`, `phone`, `phoneHref` | Контакты в футере. `phoneHref` — без пробелов и скобок. |
| `whatsapp`, `telegram` | Запасные каналы связи. |
| **`bookingUrl`** | **Ссылка на вашу операционку.** Пока пусто — все кнопки «Записаться» ведут в WhatsApp, а если и его нет, то в Instagram. |
| `mapUrl`, `coords` | Ссылка на карту и координаты студии. |
| `counters` | Числа в блоке «Комьюнити»: резиденты, студии, направления. |

Адрес и часы работы — текст переводимый, поэтому живёт в словарях:
`contact.address` и `contact.hours` в каждом из трёх файлов `src/i18n/dict/`.

### 2. `src/lib/content.ts` — мастера, направления, события

**Мастера** (`artists`). Сейчас там шесть плейсхолдеров. Для каждого реального:

1. Положите портрет в `public/images/artists/<slug>.jpg` — вертикальный кроп 3:4, минимум 900×1200.
2. Пропишите `photo: "/images/artists/<slug>.jpg"`.
3. Заполните `instagram` полным URL профиля.

Карточка без `photo` показывает типографскую заглушку с инициалами, поэтому сетка
не разваливается, пока вы собираете материал. Карточка без `instagram` показывает
кнопку «Записаться» вместо «Портфолио».

**Направления** (`styles`) — девять штук, названия и описания на трёх языках.
Поле `tag` (латиница) идёт в бегущую строку, где смесь алфавитов выглядит грязно.

**События** (`events`) — гест-споты, конвенции, семинары, флеш-дни.
Прошедшие отсеиваются автоматически (`upcomingEvents`), сортировка по дате.
Если список пуст, секция показывает текст-заглушку со ссылкой на Instagram.

### 3. Тексты

`src/i18n/dict/en.ts` — эталон: его тип `Dictionary` обязаны реализовать
`ru.ts` и `az.ts`. Добавили ключ в `en` — TypeScript потребует его и в двух других.

## Структура

```
src/
  app/
    [locale]/
      layout.tsx            корневой layout: preload шрифтов, метаданные, <html lang>
      page.tsx              сборка секций + JSON-LD Organization
      opengraph-image.tsx   OG-картинка 1200×630, генерится на лету
    globals.css             дизайн-система: токены, слои, компонентные классы
    fonts.css               @font-face — генерится скриптом, руками не править
    robots.ts, sitemap.ts
  proxy.ts                  редирект / → /<язык> по Accept-Language
  i18n/                     локали и словари
  lib/
    site.ts                 контакты и цифры
    content.ts              мастера, направления, события
    links.ts                куда ведут кнопки записи, id секций
    scroll.ts               общее состояние скролла между DOM и WebGL
  components/
    three/                  Scene, Mark (3D-знак), InkField (частицы)
    sections/               Hero, About, Styles, Artists, Events, Booking, Contact
    ui/                     Nav, Reveal, Marquee, Cursor, SmoothScroll, MarkIcon
```

### Дизайн-система

Токены — в `@theme` в `globals.css`: палитра (`--color-void` … `--color-blood`),
шрифты, кривые анимации. Компонентные классы лежат в `@layer components`, чтобы
утилиты Tailwind (`hidden`, `md:inline-flex`) всегда их перебивали.

### Шрифты

**Oswald** (заголовки), **Manrope** (текст), **JetBrains Mono** (подписи) —
вариативные, лежат в `public/fonts`, объявлены в `src/app/fonts.css`.

Они намеренно **не** подключены через `next/font/google`: тот загрузчик качает
файлы во время `next build`, и сборка начинает зависеть от доступности
`fonts.gstatic.com`. Именно это уронило прод-сборку на Vercel — Node резолвит
AAAA раньше A, и на машинах, где IPv6 анонсирован, но не маршрутизируется,
undici висит на мёртвом сокете до таймаута.

У каждого семейства три субсета — `latin`, `latin-ext` (азербайджанские
`ə ğ ı ö ş ü ç`) и `cyrillic`. `unicode-range` заставляет браузер скачать только
нужные: русский посетитель не получит латинское расширение. Всего 186 КБ на
девять файлов, реально загружается два-три.

Обновить или добавить субсет:

```bash
npm run fonts
```

Скрипт `scripts/fetch-fonts.mjs` перекачает файлы и перегенерирует `fonts.css` —
править `fonts.css` руками не нужно, он перезаписывается.

### 3D-знак

`components/three/Mark.tsx` собирает логотип из геометрии: кольцо из четырёх дуг,
четыре узла-сферы снаружи разрывов и тонкая внешняя окружность. Пропорции
(`NODE_GAP`, `NODE_DISTANCE`) совпадают с SVG-версией в `ui/MarkIcon.tsx`.

Объект не крутится свободно, а качается в пределах ±30°: при полном обороте
кольцо дважды встаёт ребром и знак перестаёт читаться. Скролл двигает его вбок,
уменьшает и вращает в плоскости экрана — силуэт при этом сохраняется.

Сцена деградирует сама:

* `prefers-reduced-motion` или нет WebGL → статичный SVG-знак вместо канваса;
* коснитесь-экран, узкий вьюпорт или ≤4 ядра → ниже DPR, меньше частиц, без мультисэмплинга;
* без JavaScript → `<noscript>`-стиль раскрывает весь текст, который иначе ждёт появления в зоне видимости.

## Деплой

Из-за `proxy.ts` (определение языка) нужен Node-хостинг, не статика.

**Vercel:** импортировать репозиторий, **Root Directory** — `site`, добавить
переменную `NEXT_PUBLIC_SITE_URL`, дальше по умолчанию. Домен подключается в
настройках проекта.

**Свой сервер:**

```bash
npm ci && npm run build && npm run start
```

Задайте переменную окружения `NEXT_PUBLIC_SITE_URL` со своим доменом (без слеша
в конце) — иначе canonical, Open Graph и `sitemap.xml` будут указывать на
домен-заглушку из `src/lib/site.ts`.

Если Node-хостинга нет, язык можно определять на клиенте: удалить `src/proxy.ts`
и добавить редирект `/` → `/az` в `next.config.ts`. Тогда сайт разворачивается
как статика.

## Проверки

```bash
npm run build
```

```bash
npx eslint src
```

`next build` гоняет TypeScript. ESLint включает правила React Compiler — они ловят
нечистые вычисления в рендере и `setState` внутри эффектов, поэтому лучше не
отключать их, а править по существу.
