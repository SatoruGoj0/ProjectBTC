# Project BTC — Baku Tattoo Community

Репозиторий комьюнити. Сейчас здесь маркетинговый сайт-визитка; операционка
(запись/CRM) живёт отдельно и подключается одной ссылкой — см. ниже.

```
site/    сайт-визитка: Next.js 16, три языка (AZ / RU / EN), 3D-знак на WebGL
```

Документация по сайту — в [`site/README.md`](site/README.md): что заполнить перед
публикацией, где лежат мастера и события, как устроена дизайн-система.

---

## Запуск локально

```bash
npm --prefix site install
```

```bash
npm --prefix site run dev
```

Откроется <http://localhost:3000>, корень редиректит на язык по `Accept-Language`.

## Деплой на Vercel

**Важно:** сайт лежит в подпапке, поэтому при импорте нужно указать Root Directory.

1. Vercel → **Add New** → **Project** → импортировать `SatoruGoj0/ProjectBTC`.
2. В блоке **Root Directory** нажать **Edit** и выбрать **`site`**.
   Framework Preset после этого сам определится как Next.js — остальное не трогать.
3. **Environment Variables** → добавить:

   | Name | Value |
   | --- | --- |
   | `NEXT_PUBLIC_SITE_URL` | `https://ваш-домен.com` (без слеша в конце) |

   Это подставляется в canonical, Open Graph и `sitemap.xml`. Без неё сайт
   соберётся и будет работать, но ссылки в шеринге укажут на домен-заглушку.
4. **Deploy**.
5. Домен: Project → **Settings** → **Domains** → добавить свой и прописать у
   регистратора записи, которые покажет Vercel. После привязки домена значение
   `NEXT_PUBLIC_SITE_URL` поправить на боевое и передеплоить.

Нужен именно Node-рантайм (не статика): `site/src/proxy.ts` определяет язык
посетителя по заголовку `Accept-Language`. На Vercel это работает из коробки.

## Что ещё не заполнено

Всё фактическое собрано в двух файлах, помечено `TODO`:

* **`site/src/lib/site.ts`** — год основания, телефон, почта, Instagram, карта,
  счётчики и **`bookingUrl`** (ссылка на операционку). Пока `bookingUrl` пустой,
  все кнопки «Записаться» ведут в WhatsApp, а если и он не заполнен — в Instagram.
* **`site/src/lib/content.ts`** — мастера, направления, календарь событий.
  Мастера сейчас плейсхолдеры без ссылок на Instagram; карточка без фото
  показывает типографскую заглушку, поэтому сетка не разваливается.

Адрес и часы работы — переводимый текст, они в `site/src/i18n/dict/*.ts`
(`contact.address`, `contact.hours`).
